# Medical Assessment Tracker (Portfolio Demo)

A single-page web app that tracks annual employee medical assessments: filter by department, manager and shift manager; see overdue and upcoming assessments; keep a health-record history per employee; and simulate email/WhatsApp reminders at 3 months, 1 month and 1 week before each assessment is due.

**All employees, names and contact details are fictional.** Data is generated relative to today's date and stored only in the visitor's browser (localStorage).

## What it demonstrates
- Requirements gathered from a stakeholder (a department manager) and turned into a working prototype
- Role-based UI (Admin / Manager / Employee) - client-side simulation only
- Reports (overdue, upcoming 30 days, by department) with CSV download
- Calendar (.ics) export for each assessment

## Built with
HTML, JavaScript, Tailwind CSS (CDN), Font Awesome.

## Notes
This public demo is a re-creation of a prototype I designed during a graduate programme. It contains no employer data or branding. In a production version, authentication, permissions, a database and a backend email/WhatsApp service would be required.
